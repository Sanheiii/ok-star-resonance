## 运行要求

- Windows 操作系统与前台运行的游戏窗口
- 16:9 游戏分辨率，最低 1280×720
- 使用源码运行时仅支持 Python 3.12
- 部分任务需要 Npcap 或 WinDivert 提供网络包捕获能力
